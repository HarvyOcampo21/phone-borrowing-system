Phone Borrowing System — one-time data migration

Run this once, on your own machine, after deploying firestore.rules. It writes directly into Firestore using the same js/firebase-config.js as the main app. Re-running it will overwrite existing docs with the same IDs — safe to re-run if an earlier run failed partway through, but don't run it against a Firestore project that already has live traffic.

In Google Sheets, open each tab and use File → Download → Comma Separated Values (.csv), then select the matching file below. Only the tabs you actually have need to be filled in.
